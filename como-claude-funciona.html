Como o Claude funciona

Uma explicação direta do mecanismo por trás do Claude, o assistente de IA da Anthropic — sem promessas, só o que de fato acontece entre você digitar e a resposta aparecer.

01 O que é, no fundo

O Claude é um modelo de linguagem grande (LLM). Na prática, é uma rede neural — especificamente uma arquitetura chamada transformer — treinada para prever qual pedaço de texto vem a seguir, dado tudo o que veio antes.

Não existe um banco de dados de respostas prontas nem regras escritas à mão para cada pergunta. Toda resposta é gerada, palavra por palavra, com base em padrões estatísticos aprendidos durante o treinamento.

02 Tokens: a unidade real de texto

O modelo não lê "palavras" — ele lê tokens, pedaços de texto (às vezes uma palavra inteira, às vezes só uma sílaba ou um pedaço de palavra). A frase "Como funciona?" pode virar 4 ou 5 tokens, por exemplo.

Cada token é convertido em uma lista de números (um vetor). É sobre esses números que o modelo efetivamente calcula — não sobre letras.

Janela de contexto: o modelo só "enxerga" um número limitado de tokens de cada vez — a conversa inteira, incluindo sua pergunta e a resposta sendo gerada, precisa caber nesse limite.

03 O caminho de uma resposta

Cada token novo é escolhido com base em toda a conversa até ali — e vira parte da entrada para prever o token seguinte.

Isso explica por que a resposta aparece em pedaços: ela está literalmente sendo calculada um token de cada vez, não escrita de uma vez e depois exibida.

04 De onde vêm as respostas: o treinamento

Antes de conversar com alguém, o modelo passa por etapas de treinamento. Resumidamente:

1

Pré-treinamento

O modelo lê uma quantidade enorme de texto e aprende, por repetição, a prever o próximo token com precisão cada vez maior. É aqui que ele absorve gramática, fatos, estilo e raciocínio implícito no texto.

2

Ajuste fino (fine-tuning)

O modelo pré-treinado é ajustado com exemplos de conversas e instruções, para se comportar como um assistente — respondendo perguntas, seguindo pedidos, formatando respostas de forma útil.

3

Alinhamento e segurança

A Anthropic aplica técnicas adicionais (como a "IA Constitucional") para incentivar respostas úteis, honestas e que evitem causar dano, comparando e ajustando o comportamento do modelo segundo princípios definidos.

05 Uso de ferramentas

Em muitos contextos (como este), o Claude pode ir além de gerar texto: ele pode chamar ferramentas externas — pesquisar na web, rodar código, ler ou editar arquivos — quando a tarefa pede isso.

O modelo não executa nada sozinho: ele decide quando pedir o uso de uma ferramenta e com quais parâmetros; quem executa de fato é o programa que está rodando o modelo (o aplicativo, o CLI, etc.), que devolve o resultado para o modelo continuar a resposta.

06 Limites do mecanismo

Como o Claude gera texto por previsão estatística, e não por consulta a uma fonte de verdade, isso tem consequências diretas:

LimitePor quê
Pode errar com confiança O modelo prevê o token mais plausível, não necessariamente o correto — erros factuais ("alucinações") são um efeito colateral direto de como ele funciona.
Conhecimento tem uma data-limite O que o modelo "sabe" vem do texto usado no treinamento, que tem uma data de corte — eventos posteriores só chegam a ele via ferramentas como busca na web.
Não lembra de uma conversa para outra Por padrão, cada conversa começa do zero; o modelo não tem memória persistente própria fora do que está na janela de contexto atual.
Herda vieses dos dados Padrões, desequilíbrios e preconceitos presentes no texto de treinamento podem aparecer nas respostas, mesmo com ajustes para mitigá-los.
